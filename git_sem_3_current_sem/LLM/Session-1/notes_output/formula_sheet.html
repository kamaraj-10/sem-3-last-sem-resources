Formula Sheet · Session 1

Large Language Models for Generative AI (S1-26_AIMLCZG536) · Prof. Monali Tushar Mavani
12 formulas
12 formulas in total: 6 taught in lecture (L) and 6 beyond the lecture (B). Beyond-lecture formulas are restatements, derived helpers or recaps, and are marked as such in their source part.
F1 · Chain rule for a sentence · part 02 · L
P(w1, …, wn) = nΠi=1 P(wi | w1, …, wi−1)
  • wi i-th token
  • n number of tokens (integer ≥ 1)
  • P probability in [0, 1]. Context is empty for i = 1
Check: 0.05 × 0.2 × 0.01 × 0.1 = 0.01 × 0.01 × 0.1 = 10−5 (log form: −11.513).
F2 · Softmax over the vocabulary · part 03 · L
P(wi | context) = eziVΣj=1 ezj
  • zi logit of token i, any real number
  • V vocabulary size (e.g. 50,000)
  • Outputs lie in (0, 1) and sum to 1
Check: logits [2.0, 1.7, 0.9, 0.3] → ez = [7.389, 5.474, 2.460, 1.350], sum 16.673, first = 7.389/16.673 = 0.443.
F3 · Vocabulary size of a BPE tokenizer · part 04 · L
|V| = base symbols + merges (+ special tokens)
  • base symbols unique characters (BPE) or 256 bytes (byte-level BPE)
  • merges number of merge rules learned (stop at the max vocab size)
  • special tokens e.g. <|unk|>, <|endoftext|>
Check: toy corpus, 7 characters + 3 merges (ug, un, hug) = 10 tokens. GPT-2: 256 + 50,000 + 1 = 50,257.
F4 · BPE pair count · part 04 · B
count(a, b) = wordsΣw freq(w) × occurrences of (a, b) in w
  • (a, b) adjacent symbols in the current segmentation
  • freq(w) corpus count of word w
  • Merge the highest count, provided it is at least min_freq
Check: words hug 10, pug 5, hugs 5 contain (u, g): 10 + 5 + 5 = 20. (p,u) = 17, (u,n) = 16, (h,u) = 15.
F5 · Embedding matrix size · part 06 · L
E ∈ ℝ|V| × d  ·  #params(E) = |V| × d  ·  X ∈ ℝn × d
  • |V| vocabulary size
  • d embedding dimension (BERT 768, Llama 3 8B 4,096)
  • n input length in tokens. X holds the n selected rows
Check: Llama 3 8B, 128,256 × 4,096 = 525,336,576 ≈ 525 M. Toy E: 6 × 3 = 18 values, X for 4 tokens = 4 × 3.
F6 · Embedding lookup as a one-hot product · part 06 · B
x = eid · E = E[id]
  • eid one-hot row vector of length |V| with a 1 at the token ID
  • E[id] row id of the embedding matrix, a vector of length d
Check: id = 2, e = [0,0,1,0,0,0], E[2] = [1.28, −0.20, −0.16] (fox).
F7 · Sinusoidal positional encoding · part 07 · B
PE(pos, 2i) = sin pos100002i/d  ·  PE(pos, 2i+1) = cos pos100002i/d
  • pos position (0, 1, 2, …)
  • i sin/cos pair index, 0 … d/2 − 1
  • Values in [−1, 1]
Check: d = 4, pos = 1 → [sin 1, cos 1, sin 0.01, cos 0.01] = [0.8415, 0.5403, 0.0100, 1.0000].
F8 · Input embedding (learned / sinusoidal position) · part 07 · L
xt = E[idt] + P[t]
  • E[idt] token embedding at position t
  • P[t] positional embedding (same size d)
  • With RoPE, position is not added here but applied to Q and K in each attention layer
Check: token [0.5, −0.2, 0.1, 0.3] + PE(1) = [1.3415, 0.3403, 0.1100, 1.3000].
F9 · Course marks · part 01 · L
Total = A1 + A2 + Mid + End
  • A1 = 15, A2 = 20 (group assignments)
  • Mid = 30 (closed book), End = 35 (open book)
Check: 15 + 20 + 30 + 35 = 100. Exams = 65 %, assignments = 35 %.
F10 · Weight memory of a model · part 01 · B
Memory ≈ Nparams × bytes per parameter
  • Nparams number of parameters
  • bytes per parameter 2 for 16-bit, 4 for 32-bit
  • Weights only. Training needs extra for gradients, optimizer state and activations
Check: 7 × 109 × 2 B = 14 × 109 B = 14 GB, which fits in a 40 GB L40S.
F11 · Chance a sentence has no [UNK] · part 09 · B
P(no [UNK]) = (1 − p)n
  • p probability a token is unknown, assumed independent
  • n tokens per sentence
Check: p = 0.03, n = 40 → 0.9740 = e−1.218 = 0.296, so about 70 % of sentences contain [UNK].
F12 · Visible attention cells: causal vs full · part 08 · B
cellscausal = n(n + 1)2  ·  cellsfull = n2
  • n number of tokens
  • Decoder-only models use the causal count, encoder-only models use the full count
Check: n = 4 → 4 × 5 / 2 = 10 vs 16, which is 62.5 %.
